# Regional Sales & Profit Analytics — Power BI

## 📊 Project Overview

This project is an interactive **Power BI dashboard** designed to analyze regional sales and profit performance.

The dashboard helps users understand sales trends, profitability, regional performance, and other important business KPIs.

## 🎯 Project Objectives

* Analyze total sales and profit
* Compare performance across different regions
* Identify high-performing and low-performing areas
* Analyze sales and profit trends
* Present important business KPIs
* Implement **Row-Level Security (RLS)**
* Create an interactive and user-friendly Power BI dashboard

## 🛠️ Tools & Technologies

* Power BI
* Power Query
* DAX
* Data Visualization
* Row-Level Security (RLS)

## 🔐 Row-Level Security

Row-Level Security (RLS) has been implemented in the Power BI project to control access to regional data based on user roles.

## 📈 Dashboard Highlights

The dashboard provides insights into:

* Regional Sales Performance
* Regional Profit Performance
* Sales & Profit KPIs
* Regional comparisons
* Business performance trends

## 💡 Key Insights

The dashboard can be used to identify:

* Which regions generate higher sales
* Which regions generate higher profit
* Areas with weaker performance
* Regional trends and performance differences

## 🚀 How to Use

1. Download the `.pbix` file.
2. Open it using Power BI Desktop.
3. Refresh the data if required.
4. Explore the dashboard using the available filters and visuals.
5. Use the appropriate role to test the Row-Level Security implementation.
