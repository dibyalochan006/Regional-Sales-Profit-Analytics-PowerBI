# Regional Sales & Profit Analytics — Power BI

## 📊 Dashboard Preview

## 📊 Project Overview

This project is an interactive Power BI dashboard created to analyze regional sales and profit performance.

The dashboard helps users understand key business KPIs, compare regional performance, identify high- and low-performing areas, and explore sales and profit trends.

## 🎯 Project Objectives

- Analyze total sales and total profit
- Compare sales and profit across regions
- Identify high-performing and low-performing regions
- Analyze business performance using interactive visuals
- Present important KPIs in an easy-to-understand dashboard
- Implement Row-Level Security (RLS)

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Visualization
- Row-Level Security (RLS)

## 📈 Dashboard Features

The dashboard provides analysis of:

- Sales performance
- Profit performance
- Regional performance
- Key business KPIs
- Sales and profit comparisons
- Interactive filtering
- Regional data access using RLS

## 🔐 Row-Level Security (RLS)

Row-Level Security (RLS) is implemented in this Power BI project.

RLS helps restrict users so that they can view only the regional data they are authorized to access.

## 💡 Business Insights

The dashboard can help business users:

- Identify regions with strong sales performance
- Identify regions generating higher profit
- Compare regional performance
- Find areas that may require improvement
- Make data-driven business decisions

## 🚀 How to Use the Project

1. Download the `.pbix` file.
2. Open it using Power BI Desktop.
3. Refresh the data if required.
4. Explore the dashboard using the available filters and visuals.
5. Use Power BI's role functionality to test the Row-Level Security implementation.
